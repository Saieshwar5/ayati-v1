# Personal attention on Home

The OpenPencil `workspace-attention.pen` document was created from the actual
connected document inventory, then selected and edited before application UI
changes. Other open designs were preserved.

- `desktop-concept.png` and `phone-concept.png` explore the Home summary,
  source-labelled flat inbox rows and quiet Recent work view.
- `attention-inbox-desktop.png` and `attention-recent-mobile-dark.png` are
  inspected captures of the implemented local application, with synthetic test
  content. The current shared Dialog drawer and design tokens determine the
  final frame/spacing. No generated image was used to implement the UI.

The [runtime contract](../../runtime/workspace-attention.md) records current
audiences, personal read/review state, retained private-runtime adapter, checks
and remaining notification scope. A notice is never an answer or an approval.
