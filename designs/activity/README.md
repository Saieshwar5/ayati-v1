# Activity (approved 2026-10-30)

Approved by the owner on 2026-10-30; building is deferred (D235). It adds a new main-menu place, **Activity**:
Home · Chat · Activity · Agents · Library · Settings.

Each place has one job:

| Place | Job |
| --- | --- |
| Home | Live dashboard panels |
| Chat | People and agents working together |
| Activity | Everything agents do, around the clock, and everything that needs a person |
| Agents | Setting agents up |
| Library | What agents know |

Activity covers the agent half of the Workboard plan (D223). Tasks owned by people
could join the same list later. The example company, people and numbers are
fictional.

| File | Screen |
| --- | --- |
| `1-needs-me.png` | Approvals, questions and requests that need review, from every agent, with a details panel to approve or reject |
| `2-now.png` | "While you were away" summary, every agent's state, and requests running now (with Stop) |
| `3-history.png` | Everything agents did: totals, requests per day, requests by agent, filters, timeline |
| `4-request-details.png` | A failed request opened: what the agent actually did, why it failed, and how to fix it |
| `5-phone.png` | Needs me and Now on a phone |

These connect to other approved plans:

- **Agents (D233):** an agent's Activity tab is this page filtered to that agent.
- **Needs me** replaces today's "Needs you" pop-up. Home keeps a small panel that
  opens it.
- **Settings (D232):** its admin "Activity" page would be renamed "Audit log".
- **Who sees what** follows the access model (D231): admins see all agents,
  managers see their agents, and others see their own requests and those in their
  channels.

`activity.fig` is the editable OpenPencil source.
