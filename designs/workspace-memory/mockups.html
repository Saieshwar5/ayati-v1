Design proposal · not built

One memory for the whole workspace

Agents save what they learn while working. Every agent uses it. Only admins see it and control it, on one new page in Settings. The memory can grow very large because it keeps itself tidy: old notes are summarised, unused notes fade, wrong notes are ended, and what matters most is always in front of the agents.

Every admin-only page already lives in Settings (People, Apps, Agent rules, Audit log). Memory joins them, so members never see it and the rail gets no new item.

How it works · 1

Three shelves, so the memory can be huge and the agent's reading stays small

A person does not replay every meeting with a client. They hold a few things they always know, a picture of each client, and old details they can look up. The memory is built the same way.

Essentials

about 30 lines

What it is: the few facts every agent must always know. Pinned by an admin, or the strongest notes.

How agents get it: with every request, always.

Topics

hundreds

What it is: one page per customer, system, process, team or project, with a short summary written from its notes.

How agents get it: Cuckoo reads the request and adds the 3 topics that match it best.

Notes

tens of thousands

What it is: single short facts, each with the agent that saved it, where, when and its strength.

How agents get it: only by searching, when the essentials and topics are not enough.

Essentials and matching topics together stay under a fixed size (about 7,000 characters). A workspace with 50,000 notes costs an agent the same reading as one with 500.

How it works · 2

The life of a note

No note stays forever by default. Each one moves along this line by itself, and an admin can move it by hand at any point.

  1. NewAn agent saves it while working. Checked for duplicates and for a source everyone may see.strength starts at 40–90
  2. ActiveAgents find it. It feeds its topic's summary. Use makes it stronger.strength 30 or more
  3. FadingNot used for a long time. Still searchable, ranked last, listed for the admin.strength 10–29
  4. ArchivedAgents no longer see it. An admin can bring it back.strength under 10
  5. DeletedRemoved for good after 12 months in the archive.the admin sets how long
PinnedAn admin's choice. Never fades, never summarised away, wins over other notes.
EndedIt stopped being true. Kept beside the note that replaced it, unused, so the history is clear.
In the summaryAn old note whose content now lives in its topic's summary. Kept as evidence, not sent to agents again.

How it works · 3

Strength: which notes get preference, and how they fade

Every note has one number from 0 to 100. It answers two questions together: how sure are we? and is it still useful? When two notes compete, the stronger one wins.

What makes a note stronger

  • An agent noticed it once starts at 40
  • A person said it in a shared conversation starts at 60
  • An admin wrote or confirmed it set to 90
  • A second agent learned the same thing by itself +15
  • Used in an answer nobody corrected +3, and the clock restarts
  • Pinned by an admin always first

What makes a note weaker

  • Time passing without use halves, see below
  • A person corrects an answer that used it on hold, admin asked
  • A newer, stronger note says the opposite ended
  • Its end date arrives ("until 28 Nov") ended that day
  • An admin marks it no longer true ended

Different kinds of fact fade at different speeds

Each line is a note that started at 60 and was never used again. A status is gone in weeks. A decision lasts over a year.

A note that starts at 60 reaches Fading after one such period. These are starting values, to be tuned on a real workspace. A note that agents keep using never fades, because each use restarts its clock.

How it works · 4

The nightly tidy-up

Once a night Cuckoo cleans the memory, in this order. Everything it does is listed under Changes on the Memory page, and an admin can undo any line.

  1. End what has expiredNotes with a date ("until 28 Nov") end on that date.
  2. Merge duplicatesTwo notes that mean the same become one. Their strength and their uses add up.
  3. Settle disagreementsThe newer, stronger note wins and the other is ended. If they are close, an admin is asked.
  4. SummariseA topic with more than 25 notes, or notes older than 90 days, gets its summary written again. Those notes move into the summary.
  5. FadeEvery unused note loses strength by its kind. Notes cross into Fading, then Archived.
  6. DeleteArchived notes older than the keep time are removed for good.
  7. Choose the essentials againPinned notes first, then the strongest and most used, up to the size limit.
  8. Clean the summariesA sentence whose notes are all archived leaves its summary, unless it is pinned.

Rules that keep it safe

What an agent may save

  • Only from places the whole workspace may see: public channels and Library items shared with the workspace. Private chats and restricted folders are refused by the server. Members can't open the memory, but agents repeat it in answers to everyone, so nothing private may enter it.
  • Outside text waits for an admin: anything from email, the web or a connected app goes to Needs your answer first.
  • Facts, never instructions: a note can say what is true. It can never tell an agent what to do; only people write rules.
  • Agents add and end, never rewrite or erase. Only an admin changes wording or removes for good.
  • No secrets: passwords, keys and card numbers are refused.
