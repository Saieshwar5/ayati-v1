# Shared connected-system event work

`shared-agent-events.pen` is an editable OpenPencil document created after listing
actual connected documents and inspecting the selected Agents Automation design.
Desktop/phone concepts were saved and inspected before application UI edits;
existing open documents were preserved. SVGs are actual OpenPencil exports; PNG
concepts were rendered from those vectors locally with librsvg and inspected.

The concept shows a reviewed source/account, included fields, destination audience,
original human principal, exact filter and independent action approval. The
[runtime contract](../../runtime/shared-agent-events.md) records supported behavior.

The `events-*.png` files show actual implemented local UI with synthetic fixture
data: creation review, saved deliveries, phone and dark phone review. These are
local browser captures, separate from the concepts. Provider subscription setup,
HTTPS ingress, real provider delivery and cloud acceptance were not performed.
