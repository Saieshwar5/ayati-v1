# Versioned conversation context

OpenPencil concept created and visually inspected on 2026-10-26 before changing
React. `context.fig` contains the selected existing context preview and a new
Versioned conversation context page. Preserve the quiet workspace frame, flat
source rows, bounded drawer scrolling and accessible disclosure controls.

Current context is distinct from saved input and later retrieval receipts.
Summaries are labelled interpretations. Unavailable historical text is hidden.
Only the requester's own task snapshots are inspectable, with current conversation
and agent access. Other protected source content stays in its source-aware reader.
