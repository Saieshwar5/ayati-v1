# Agent job guidance and draft-only samples

The editable `agent-job-rehearsal.pen` document was created after inspecting the
actual OpenPencil document inventory, selected and edited before application UI
changes. Existing open documents and the selected Agents B layout were preserved.

`desktop-concept.png` and `phone-concept.png` show the proposed job/context review
and saved draft workflow. The three `sample-*.png` files are inspected captures
of the implemented local application with synthetic fixture content: desktop
context review and saved result, plus the shared reader in a phone/dark window.
The existing drawer, reader and design tokens define the final application frame.

[The runtime contract](../../runtime/agent-job-rehearsal.md) explains scope,
source privacy, exact Start/Stop receipts, recovery and verification. A sample
has no connected action capability and does not activate business permissions.
