# Personal pins and channel archive

The separate [OpenPencil document](chat-organization.pen) was selected and saved
before application changes. Its [desktop](concept-desktop.png) and
[phone](concept-mobile.png) concepts use illustrative content. Archived entries
leave active Pinned; their personal preference can return on restore. Custom
reordering is deferred in favor of stable pin-time order.

Checked application captures:

- [Archive review and visible unfinished work](archive-review-desktop.png)
- [An archived thread with saved answer and exact approval](archived-thread-mobile-dark.png)
- [Restored pins, unread state and preserved draft/file](restored-pinned-desktop.png)

The actual journey uses real pinned Goose, a scripted local model and an
independent authenticated MCP fixture. JSON-looking response text is fixture
output, not text hard-coded into the product. It confirms exactly one reviewed
write and verifies draft/file retention, closed intake, source revocation and
restart. These are local application checks, not cloud or commercial acceptance.
See [the runtime contract](../../runtime/chat-organization.md).
