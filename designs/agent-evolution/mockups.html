Design proposal · not built

Agents that get better on their own

Every answer gets an outcome. Every three days each agent looks at its routine work and, where it has no skill for a job it keeps doing, writes one, tries it on past requests and proposes it. People approve it, and the skill says Created by Nova forever. Each week shows in numbers whether the agents improved.

The loop

Seven steps, around and around

The purple steps are new. The rest exist today.

  1. WorkAnswers and tool runs
  2. SignalsEach answer: accepted, corrected, followed up
  3. LearnNotes, job types, skill drafts
  4. CheckClassifier, then rehearsal on past requests
  5. ReviewA person approves
  6. UseNotes chosen by meaning; new skills
  7. MeasureThe learning score each week

How the three-day review decides

From routine work to a skill

  1. Due?72 hours since the last review and at least 10 new requests. Otherwise it waits.
  2. Sort into job typesThe last 30 days of requests, grouped by meaning and confirmed by the classifier.
  3. Find routine workA job done at least 5 times on 3 different days.
  4. Is there a skill?Covered, partly or not. Mostly accepted with no skill: draft one. A skill often corrected: draft a new version. A job gone for 60 days: suggest retiring.
  5. DraftWritten from how the good runs went. Message text only from shared conversations; private chats give only job type and steps.
  6. CheckNo secrets, names, addresses, amounts or scripts; only apps it already has.
  7. RehearseTried on 3 past requests with no tools. Any "worse" drops the draft.
  8. Propose, then measureA person approves. After 14 days, before and after are compared.

The classifier

One small model, many small decisions

Each question has fixed answers and a confidence. High confidence acts, the middle asks a person, low is dropped. Every answer is stored so it can be checked.

Build order

Seven steps, each useful alone

  1. E1 · Classifier and meaningThe classifier service, embeddings, meaning search for memory.
  2. E2 · OutcomesEvery answer gets an outcome; shown in Activity.
  3. E3 · Memory learns from outcomesCorrected answers hold their notes; checks on every new note; notes chosen by relevance.
  4. E4 · Duplicates and contradictionsBy meaning; grouped searches; room members see room notes; assistant memory joins the engine.
  5. E5 · Job typesEach request sorted into the agent's jobs.
  6. E6 · Skill reviews every three daysDrafts, rehearsal, proposals, "Created by Nova".
  7. E7 · MeasuringThe learning score; each skill's effect; retiring what doesn't help.
