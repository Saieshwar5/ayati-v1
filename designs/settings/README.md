# Approved Cuckoo Settings design

Option **B — Personal / Workspace tabs** was selected on 2026-10-22.

- `b-owner.png`: Owners see Personal and Workspace. People and invitations are within Workspace.
- `b-user.png`: Users see personal settings, without workspace administration.
- `cuckoo-settings-options.fig`: editable OpenPencil source containing the six comparison frames. The two B frames are the approved implementation reference; A and C are alternatives.

Settings remains in everyone's global navigation. Users, Company and Feedback no longer have global navigation entries. Workspace membership has two roles, Owner and User; all owners have equal authority, with at least one owner required. Resource sharing stays explicit. Designs use example identities and a fictional workspace.

Implementation should preserve the current semantic theme tokens, quiet grey global rail, rounded workspace surface and account-menu workspace switching. The mockup search is not required until there is enough settings content to justify it. Personal theme preferences retain their current device-local scope.
